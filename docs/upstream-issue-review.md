## Protocol sources and limits

[Official 2025-11-25 specification](https://modelcontextprotocol.io/specification/2025-11-25) and [official 2026-07-28 specification](https://modelcontextprotocol.io/specification/2026-07-28) both exist. The latter changes the protocol toward stateless self-contained requests; migrate the complete supported contract rather than simply suppress the third-party sweep's failing cases. Parent raw stdio handshake confirms #136 is resolved locally. The third-party sweep targets upstream `@coding-solo/godot-mcp`, not our current source.

Claims from comments are treated as reporter evidence, not authoritative platform facts: notably AntiGravity OAuth assertions, GUT flags, screenshot flipping across renderers, and .NET stripping all need official docs or local reproduction. The API issue/comments inventory was fetched read-only; no upstream comments or issues were posted.
